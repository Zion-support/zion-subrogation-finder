# Subrogation Finder

## Implementation status — 9 October 2026
This repository is documentation only (README). No runnable app, AI model, claim analysis endpoint or deployed recovery system is included. The features below are proposed, not implemented or certified. Use synthetic examples and qualified human review; do not upload confidential claims or treat this concept as a legal entitlement to recover funds.

## Proposed workflow
Recovery and subrogation opportunity detection across closed claim files. Intended audience: insurers, MGAs, brokers and claims teams. A future implementation must document evidence, limitations, permissions and qualified legal review.
